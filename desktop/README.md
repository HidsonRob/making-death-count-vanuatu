# Making Death Count – Vanuatu (desktop)

Electron wrapper for the local dashboard. Loads `../index.html` so it works offline.

## Run

```bash
cd desktop
npm start
```

Requires Node.js. If dependencies are not installed yet:

```bash
cd desktop
npm install
npm start
```

The GitHub Pages site can also be installed as an app from the browser (PWA) via the install icon in Chrome/Edge.
